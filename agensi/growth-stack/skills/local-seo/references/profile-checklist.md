# Profile and listing checklist

Work through it with the user. Mark each line done, not applicable, or needs the user.

- [ ] Business name exactly as it appears on the shopfront and the site. No added keywords.
- [ ] One primary category that matches the main service, and only the secondary categories that are true.
- [ ] Address matches the site character for character; service areas listed if the business travels.
- [ ] Phone number: the one customers can actually reach, the same as on the site.
- [ ] Opening hours, including holidays. Update before each holiday.
- [ ] Website link goes to the page that serves that location, not a generic homepage when a location page exists.
- [ ] Services listed with plain descriptions and, where the user has them, real prices.
- [ ] Description in the business's voice: what, for whom, where. No promotional claims you cannot support.
- [ ] Photos: the exterior, the inside, the team, the work. Real ones the user owns.
- [ ] Questions and answers seeded with the three things customers ask most.
- [ ] Review link ready and a reply routine agreed.

## Citations

Order of effort: the business profile, the two or three directories customers in this trade actually use, then the rest.
Use the same name, address and phone as the source of truth. Record the date each was checked.

## Location page outline

1. H1: service and place in the words customers use.
2. First paragraph: who you are, where, who you serve.
3. Services with plain detail.
4. Directions, parking, hours.
5. Local proof the user can show: named work done in the area, a real review with permission.
6. Questions customers in this area ask.
7. One call to action and the phone number as text.
