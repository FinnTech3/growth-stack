# Launch timeline template

T is launch day. Delete rows the tier does not need.

| When | Task | Owner | Done when |
|---|---|---|---|
| T minus 14 | Goal, tier and audience agreed | | Written and signed off |
| T minus 14 | Launch page drafted | | `growth-loop` audit run, critical items listed |
| T minus 10 | Measurement set up | | Each event fires in a test (see `measurement-plan`) |
| T minus 7 | Emails and posts drafted | | Reviewed by the owner |
| T minus 5 | Help docs and support answers | | Top five questions answered |
| T minus 3 | Dry run on staging | | Form, payment or booking works end to end |
| T minus 1 | Go or no-go meeting | | Every criterion checked |
| T | Launch | | Page live, tracking confirmed |
| T plus 1 | Check the numbers and support inbox | | Issues logged |
| T plus 7 | One-week review | | Same metrics as the baseline |
| T plus 14 | Two-week review | | Lessons and next steps written |

## Go and no-go

- [ ] Page returns 200 and the audit has no critical gap.
- [ ] The conversion event fires in a real test.
- [ ] Support can answer the top five questions.
- [ ] The rollback is written and someone owns it.

## Review template

Goal, result, baseline, what changed, what we learned, what we will do next, what we could not measure.
