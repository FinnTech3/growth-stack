# Landing page structure

## Hero

| Element | Rule | Fictional example |
|---|---|---|
| Headline | The outcome for the visitor, up to about 12 words | Your bike back, fixed, by end of day |
| Subhead | How, and for whom | Collection and return within five miles of Harbour Street |
| Button | A verb and the result | Book my repair |
| Proof line | One real fact beside the button | Family-run workshop on Harbour Street (use only what the user can show) |

## Below the hero, in the order of the visitor's doubts

1. How it works: three steps, each one line.
2. Proof: a real quote with permission, a number from the user's own records, a named client.
3. Objections: price, time, risk, fit; answer each in two sentences.
4. The button again, with the same label.

## Form rules

Ask only what the next step needs. Name and a way to reply is usually enough. Put the optional questions after the conversion.

## Review checklist

- [ ] The headline matches the promise that brought the visitor.
- [ ] One primary button, verb-led, repeated at the end.
- [ ] Form of five fields or fewer.
- [ ] Contact details visible as text.
- [ ] Privacy and terms linked.
- [ ] Proof is real and near the button.
- [ ] The page works on a phone and loads quickly (check with the user's own tools).
