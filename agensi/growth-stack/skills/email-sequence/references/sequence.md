# Sequence map

| # | Delay after trigger | Purpose | One call to action | Stops when |
|---|---|---|---|---|
| 1 | Immediately | Confirm and set expectations; deliver what was promised | The first useful step | Goal event done |
| 2 | 1 to 2 days (judge by the product) | Remove the biggest doubt | A short guide or the next step | Goal event done |
| 3 | 3 to 5 days | Show proof the user holds | See the real example | Goal event done |
| 4 | 7 days | Ask for the conversion plainly | The goal action | Goal event done |

This is a starting shape, not a rule. Add or drop emails by purpose.

## Template for each email

```
Subject A / B:
Preview:
Body (one idea, short paragraphs, the sender's name):
Call to action (one link, tagged):
Footer: sender, why you got this, unsubscribe
```

## Checks

- Reading: aim for the reading ease of the user's best existing email, not a number from a book.
- Length: transactional and onboarding emails are usually short; judge by the purpose, and cut anything that does not serve it.
- Voice: you above we. Say what the reader gets.
